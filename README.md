# jobsearchtracking
This project is to use google spreadsheets as a job search tracking activity


Step 1:
Make your own copy of this spreadsheet:
File > Make a Copy

https://docs.google.com/spreadsheets/d/1QaB6toLxA3B4MwaJZ-tV8kMV5VbZrNMiep4t__1PYpg/edit?usp=sharing

There is a file url you will need to copy the url location and paste into your plugin.

Extensions > App Script > New Deployment > Select type > Web App > Who has access > Anyone > Deploy

Copy the url from your screen that looks like this: https://script.google.com/macros/s/*****************/exec



Step 2:
Download this Github code and unzip it locally.


Step 3:
Using the Chrome browser:
Open a tab to enable the chrome extension and install it:
1. goto: chrome://extensions
2. Turn on: Developer mode
3. Load unpacked
4. Browse to folder where it is locally on computer


Step 4: 
When you click on the plugins in your chrome toolbar, the url from step 2 is what you will paste as the Sheet Script Input
Click Save Sheet Script


Step 5: 
Change the Data Type one of the dropdown items you see fit for the current tab resource.


Step 6:
Click Send Data to my sheet


You will see data show up in your sheet in a few seconds. I have seen it take as long as 50 seconds.
